# 🏗️ Техническая архитектура Password Generator Pro

Этот документ описывает внутреннее устройство программы и механизмы защиты данных.

## 1. Схема шифрования данных
Для защиты используется библиотека `cryptography` (алгоритм AES-256 в режиме Fernet).

### 2. 🔑 Служебные файлы и файлы данных

Эти файлы автоматически создаются программой в процессе работы и определяют текущий статус безопасности и лицензии.

#### 📁 Файлы ключей (*.key)
*   **`internal.key`** (Критически важный): 
    - Генерируется при первом запуске (используя алгоритм Fernet).
    - Это «мастер-ключ» шифрования. Именно им зашифрованы данные в `passwords.dat` и сам мастер-пароль. 
    - **ВНИМАНИЕ:** При удалении этого файла доступ к старой базе паролей будет невозможен даже с верным мастер-паролем.
*   **`master.key`**:
    - Содержит хэш вашего Мастер-пароля.
    - Используется для сверки при входе в систему. Хранится в зашифрованном виде (через `internal.key`).

#### 📜 Файлы лицензии (*.lic)
*   **`license.lic`**:
    - Текстовый файл, в котором хранится введенный пользователем серийный номер.
    - При каждом запуске программа считывает этот файл и перепроверяет ключ на соответствие текущему [HWID](https://wikipedia.org) оборудования и секретной соли.

#### 📦 Файлы данных (*.dat)
*   **`passwords.dat`**:
    - Основная зашифрованная база. Содержит все логины, пароли и названия сервисов в формате JSON, упакованном в байт-строку Fernet.

#### ⚙️ Скрипты автоматизации (*.bat) — (Опционально)
Если ты создавал такие файлы для удобства разработки:
*   **`build.bat`** (или аналогичные):
    - Набор команд для терминала Windows. Позволяет одной командой запустить процесс очистки папок `dist`/`build`, выполнить обфускацию через `PyArmor` и собрать финальный `EXE` через `PyInstaller`.


## 3. Система лицензирования (HWID)
Механизм привязки к оборудованию реализован в модуле `licensing.py`.

1.  **Сбор HWID**: Используется `uuid.getnode()` или серийный номер системного диска.
2.  **Генерация ключа**: `SHA-256(HWID + SECRET_SALT)`.
3.  **SECRET_SALT**: Константа, хранящаяся в `settings.py`. Критически важна для работы `keygen.py`.
4.  **Активация**: Ключ сохраняется в `license.lic`. При каждом запуске программа сверяет ключ в файле с вычисленным значением для текущего ПК.

## 4. Модули системы
*   `password_ui.py`: Основной цикл `while True`, инициализация тем и главный интерфейс генератора.
*   `auth_ui.py`: Управление состояниями (Активация -> Регистрация -> Вход).
*   `vault_ui.py`: Динамическое построение карточек из JSON, поиск и фильтрация.
*   `security.py`: Глобальные хуки `bind_all` для отслеживания активности и таймер автоблокировки.
*   `backup_manager.py`: Логика упаковки `passwords.dat` и `internal.key` в защищенный ZIP-архив (.pback).

## 5. Пользовательские настройки
Выбор темы (Dark/Light) сохраняется в `settings.json`. Загрузка темы происходит **до** инициализации графического движка для предотвращения мерцания.

## 6. Инструкции по сборке (Deployment)
1.  **Обфускация**: Обязательное использование `PyArmor` для защиты `SECRET_SALT`.
2.  **Компиляция**: `PyInstaller` с флагом `--onefile` и упаковкой всех иконок (.png, .ico).
