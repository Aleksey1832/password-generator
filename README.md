# <p align="center">Password Generator Pro</p>

**Password Generator Pro** — это современное и безопасное десктопное приложение для генерации и хранения паролей, написанное на Python с использованием библиотеки CustomTkinter. Программа ориентирована на максимальную защиту данных и удобство пользователя.

---

## ✨ Основные возможности

*   **Генерация паролей:** Создание надежных паролей с настройкой длины и символов.
*   **Зашифрованное хранилище:** База данных защищена алгоритмом AES-256.
*   **Система лицензирования:** Привязка программы к конкретному железу (HWID) для защиты от несанкционированного копирования.
*   **Автоблокировка:** Программа автоматически закрывается при бездействии пользователя более 5 минут.
*   **Защита от подбора:** Блокировка интерфейса на 30 секунд после 3-х неверных попыток ввода мастер-пароля.
*   **Импорт и Экспорт:** Удобное создание зашифрованных бэкапов данных для переноса на другой ПК.
*   **Кастомизация:** Поддержка темной и светлой тем оформления с сохранением выбора пользователя.
*   **Интерактивный UI:** Анимация кнопок, индикатор сложности пароля и плавные переходы.

---

## 🔒 Безопасность

Проект реализует многоуровневую систему защиты:
1.  **Лицензионный ключ:** Уникален для каждого ПК (на базе HWID).
2.  **Мастер-пароль:** Хранится в виде соленого хэша. Без него доступ к базе невозможен.
3.  **Шифрование:** Используется библиотека `cryptography`. Данные шифруются ключом, который не хранится в открытом виде.
4.  **Секретная соль:** Дополнительный уровень защиты алгоритма лицензирования.

## 🚀 Установка и запуск (для разработчиков)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите основной файл:
   ```bash

   ```

## 📝 Структура проекта

*   `password_ui.py` — Главное окно генератора и логика приложения.
*   `password_manager.py` — Ядро шифрования и управление базой данных. 
*   `auth_ui.py` — Окна регистрации, входа и проверки лицензии.
*   `vault_ui.py` — Менеджер хранения паролей и карточки записей.
*   `licensing.py` — Логика HWID и верификации ключей.
*   `security.py` — Модули автоблокировки и защиты от брутфорса.
*   `utils.py` — Общие утилиты (копирование, работа с файлами).
*   `backup_manager.py` — Функции импорта и экспорта базы.
